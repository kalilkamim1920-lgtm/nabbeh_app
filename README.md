# نبّه (Nabbeh)

تطبيق يحوّل إشعارات هاتفك إلى **مهام ومواعيد ومصاريف تلقائياً** — بمعالجة 100% على الجهاز، بدون سحابة، وبدون إنترنت.

## الفكرة

الموظف والطالب يستقبلان 50-100 إشعار يومياً وأهمها يضيع بين العروض والإشعارات الترفيهية. نبّه يلتقط الإشعارات المهمة، يصنفها محلياً إلى:

| التصنيف | المعنى | التحول إلى |
|---------|--------|------------|
| `MOHTIME` | موعد | حدث في تقويم الجهاز + عنصر في لوحة اليوم |
| `MASROOF` | مصروف | معاملة مالية في الميزانية |
| `MAHMMA` | مهمة | مهمة في قائمة المهام |
| `TAJAHUL` | تجاهل | يُحفظ للمراجعة فقط |

ثم يعرضها لك في **بطاقة تأكيد بضغطة واحدة** — أنت الوحيد الذي يقرر.

## الخصوصية أولاً (القواعد الصارمة)

- **لا سحابة إطلاقاً**: الملف `AndroidManifest.xml` لا يطلب صلاحية إنترنت في وضع الإطلاق — يستحيل تقنياً إرسال بياناتك.
- **تشفير كامل**: قاعدة البيانات `Room + SQLCipher` (AES-256) والإعدادات الحساسة في `EncryptedSharedPreferences` محمية بـ Android Keystore.
- **صلاحية واحدة فقط**: الوصول للإشعارات (تُمنح يدوياً من إعدادات النظام). صلاحية التقويم اختيارية وتُطلب عند أول موعد.
- **تحكم بكل تطبيق**: عطّل رصد أي تطبيق من الإعدادات بنقرة.
- **زر "احذف كل بياناتي"**: مسح فوري ونهائي لكل شيء.

## المتطلبات

- **Flutter 3.16+** (مُختبَر حتى 3.27) — `flutter --version`
- **JDK 17** (مطلوب لـ AGP 8.7)
- **Android SDK 34+**
- جهاز **Android 7.0+** حقيقي (المحاكي لا يصدر إشعارات واقعية)

## خطوات البناء والتشغيل

```bash
# 1) فك الضغط والدخول للمجلد
unzip nabbeh_app.zip && cd nabbeh

# 2) تحميل الحزم
flutter pub get

# 3) التشغيل على جهاز حقيقي
flutter run

# 4) بناء نسخة إطلاق
flutter build apk --release
# الملف الناتج: build/app/outputs/flutter-apk/app-release.apk
```

### بعد أول تشغيل

1. افتح تبويب **الإعدادات** واضغط **"فتح إعدادات الوصول للإشعارات"** وامنح نبّه الصلاحية.
2. (اختياري) امنح **صلاحية التقويم** كي تُضاف المواعيد تلقائياً.
3. أرسل لنفسك إشعاراً تجريبياً (مثل رسالة فيها "موعد غدا الساعة 5") وستراه فوراً في **بانتظار تأكيدك**.

### لو فشل بناء مجلد android (اختلاف إصدار Flutter عندك)

```bash
# انسخ مجلد android جانباً، أعد توليده، ثم أعِد الملفات الخاصة بنا
cp -r android /tmp/android_backup
flutter create . --org com.nabbeh --project-name nabbeh
cp -r /tmp/android_backup/app/src/main/kotlin android/app/src/main/
cp /tmp/android_backup/app/src/main/AndroidManifest.xml android/app/src/main/
cp /tmp/android_backup/app/build.gradle android/app/
```

## كيف يعمل التصنيف؟

`ClassifierHelper.kt` — تصنيف هجين يعمل فوراً بدون أي نموذج:

1. **تطبيع النص العربي**: إزالة التشكيل، توحيد (أ/إ/آ → ا، ة → ه، ى → ي).
2. **كلمات موزونة** لكل تصنيف (عربي + إنجليزي): "تم خصم" بوزن 3، "اجتماع" بوزن 2...
3. **عتبة قرار**: مجموع أقل من 2.0 → `TAJAHUL`. التعادل يُحسم لأولوية: مصروف ← موعد ← مهمة.
4. **استخراج جانبي**: المبلغ مع رموز العملات، الوقت ("الساعة 9:30"، "غداً"، "بعد 3 يوم"، "15/3")، والجهة ("من متجر X").
5. **جاهزية TFLite**: ضع `nabbeh_classifier.tflite` مستقبلاً ودمج النتيجة في `classify()` لرفع الدقة.

### أمثلة قواعد (من شاشة الإعدادات)

| التطبيق | الكلمة | الإجراء |
|---------|--------|---------|
| تطبيق بنكك | `تم خصم` | تسجيل مصروف تلقائي |
| تطبيق طلبات | `تم تأكيد` | إنشاء مهمة |
| كل التطبيقات | `موعد غدا` | موعد + تقويم |
| تطبيق عروض | `خصم 50%` | تجاهل |

فعّل **"تنفيذ القواعد تلقائياً"** لتعمل بدون سؤال.

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| `flutter pub get` يفشل على intl | flutter_localizations يثبّت نسخة intl محددة — غيّر `intl:` في pubspec ليطابق ما يقوله الخطأ (مثلاً `0.20.0`) |
| فشل Gradle: JDK | ثبّت JDK 17 واضبط `org.gradle.java.home` في `android/gradle.properties` |
| لا تظهر إشعارات | تأكد من صلاحية "الوصول للإشعارات"، وأن التطبيق المصدر مفعّل في إعدادات نبّه، وأطفئ توفير البطارية لنبّه |
| فقدت قاعدة البيانات؟ | مستحيل أُفقد تشفيراً — المفتاح في Keystore؛ احذف بيانات التطبيق يعيد التهيئة |

## الأفكار القادمة

- نموذج TFLite محلي مدرّب على إشعارات عربية لرفع الدقة.
- تصدير المصاريف CSV.
- إشعارات متكررة (اشتراك شهري) بذكاء.
- وضع "لا تزعجني" بأوقات نوم.
